# Модуль 4. v4: простой RAG

> Хватит отправлять модели весь сайт. Научимся находить нужные куски и отправлять только их — это и есть RAG.

## Контракт модуля

| Что сломалось | Что изучим | Что добавим в сервис | Какую метрику двигаем |
|---|---|---|---|
| v3 отвечает верно, но каждый вопрос платит за весь сайт | HTML → текст, нарезка на куски, поиск по словам, отказ без запроса к модели | v4: поиск + ответ по найденному | Вход на вопрос: 1200 токенов → около 300 |

## Задача

В модуле 3 бот начал отвечать правильно, и мы сразу увидели цену: каждый вопрос пересылает весь сайт. На пяти страницах это копейки, на пятистах — счёт и медленные ответы.

Решение очевидно по формулировке и не очевидно по исполнению: **отправлять только те куски, которые относятся к вопросу**. Для этого сайт нужно превратить в текст, порезать на куски и научиться находить нужные.
