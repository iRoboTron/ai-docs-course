## Задача

RAG состоит из решений, каждое из которых мы приняли наугад: резать по 400 символов, искать по совпадению слов, отправлять три куска. Любое из них может оказаться плохим — и именно оно стоило нам вопроса про гарантию.

Правильный способ выбирать — **менять один фактор за раз и мерить**. Иначе после трёх правок непонятно, какая помогла, а какая навредила.
