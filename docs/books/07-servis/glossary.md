## Сервис

> **Сервис** — программа, которая отвечает на запрос независимо от того, кто и когда
> его прислал, и которую можно перезапустить без участия человека, читавшего код.

Из [урока 1](chapter-01.md). Ноутбук не сервис: переменные живут, пока жива сессия
Colab, а «протестировано» значит «посмотрели на вывод глазами».

```mermaid
flowchart TD
    A["Ноутбук: ячейки сверху вниз"] --> B["Переменные живут, пока жива сессия"]
    C["Сервис: HTTP-запрос"] --> D["Отвечает независимо от того, кто прислал"]
    style A fill:#2d2d2d,color:#fff
    style B fill:#7d6608,color:#fff
    style C fill:#2d2d2d,color:#fff
    style D fill:#1e8449,color:#fff
```

## Ключ кэша по содержимому

> **Ключ кэша по содержимому** — идентификатор записи в кэше, вычисленный из
> самих данных, а не из внешних признаков вроде даты или версии.

Из [урока 2](chapter-02.md). Хэш текста кусков: сайт поменялся — старый ключ не
совпал, кэш пересчитался сам, отдельный «срок годности» не нужен.

```mermaid
flowchart TD
    A["Куски документов"] --> B["sha256(текст кусков)"]
    B --> C["Ключ кэша"]
    C --> D{"Файл с таким ключом есть?"}
    D -->|да| E["Взять готовые векторы"]
    D -->|нет| F["Посчитать и сохранить под новым ключом"]
    style A fill:#2d2d2d,color:#fff
    style B fill:#1a5276,color:#fff
    style C fill:#4a235a,color:#fff
    style D fill:#1a5276,color:#fff
    style E fill:#1e8449,color:#fff
    style F fill:#7d6608,color:#fff
```

## Холодный старт

> **Холодный старт** — время от запуска процесса до готовности отвечать на
> первый настоящий запрос.

Из [урока 2](chapter-02.md). На нашем сервисе это в основном загрузка модели
эмбеддингов (9,4 с), а не кодирование кусков (0,76 с на 30 штук) — файловый
кэш ускоряет только вторую часть.

```mermaid
flowchart TD
    A["Запуск процесса"] --> B["Загрузка модели эмбеддингов: 9.4 с"]
    B --> C["Кодирование кусков: 0.76 с на 30 штук"]
    C --> D["Готов отвечать"]
    style A fill:#2d2d2d,color:#fff
    style B fill:#6e2f1a,color:#fff
    style C fill:#7d6608,color:#fff
    style D fill:#1e8449,color:#fff
```

## Тест без сети

> **Тест без сети** — проверка, которая не обращается ни к прокси модели, ни к
> интернету, и потому одинаково проходит и у разработчика, и в CI.

Из [урока 1](chapter-01.md). Достигается подменой зависимостей: `otvetit()`
принимает `indeks` и `ask` параметрами, тест подставляет фейковые.

```mermaid
flowchart TD
    A["Тест"] --> B["Фейковый индекс + фейковый ответ модели"]
    B --> C["Проверка цитаты и чисел — тот же код, что и в проде"]
    style A fill:#2d2d2d,color:#fff
    style B fill:#1a5276,color:#fff
    style C fill:#4a235a,color:#fff
```

## CI (continuous integration)

> **CI** — автоматический запуск тестов на каждый push, без участия человека.

Из [урока 1](chapter-01.md). Работает только потому, что тесты не зависят от сети:
CI-раннер не имеет доступа к прокси модели курса и не должен его требовать.

```mermaid
flowchart TD
    A["git push"] --> B["CI-раннер: pip install + pytest"]
    B --> C{"Все тесты прошли?"}
    C -->|да| D["Коммит помечен зелёным"]
    C -->|нет| E["Коммит помечен красным, видно всем"]
    style A fill:#2d2d2d,color:#fff
    style B fill:#1a5276,color:#fff
    style C fill:#1a5276,color:#fff
    style D fill:#1e8449,color:#fff
    style E fill:#6e2f1a,color:#fff
```
